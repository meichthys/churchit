To show your live stream on the website, open the [Church](../foundations/churches.md), and in the Contact section of the Details tab, put the link to the stream in **Live Stream Link**. The link must start with https://. The `/live` page then shows the stream:

- A YouTube video link, a youtube.com/channel/ link that ends in /live, a Let's Church media link, a PeerTube video link or an Owncast player link (it ends in /embed/video) plays on the page.

- Any other link, such as a youtube.com/@name/live link, opens the site of the stream.

- A branch church without its own link uses the link of its parent church. If no church has a link, /live shows "Page not found".

The menu has no Watch Live item at first. To add one, see [The Website Menu and Footer](the-website-menu-and-footer.md), and use the URL /live.

:::tip[Stream from a YouTube channel]
A youtube.com/@name/live link opens YouTube and does not play on your page. Use the link with your channel ID instead: https://www.youtube.com/channel/*channel ID*/live. A channel ID starts with UC. To find it, sign in to YouTube with the channel account and open https://www.youtube.com/account_advanced, then copy the **Channel ID**. This link always plays the stream that is live now, so you do not change it for each service.
:::

A channel link does not play in every browser. After you set the link, open `/live` and make sure that the stream plays. If it does not, use the watch link of each stream, for example https://www.youtube.com/watch?v=*video ID*, and put the new link on the Church before each service.
