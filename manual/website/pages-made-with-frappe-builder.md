Frappe Builder is a separate app for designing web pages by drag and drop. A System Manager can install it next to Churchit. Before you use it, note:

- Use a Builder page only for pages that show no church records, such as a landing page. A Builder page cannot keep the records of one church apart from another. Show events, sermons or people on Churchit's pages, and link to them.

- A Builder page takes its address before Churchit's own pages. Before you choose an address, open it in a private window, and use it only when it shows "Page not found". Do not use an address listed under Website Pages in Church Features, also when that page is off.

- Churchit's shipped pages (Home, Beliefs, Missions, Ministries and Sermons) stay Web Pages.
