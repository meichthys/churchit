Churchit gives your church two places on the internet. The **website** is public: anyone can read it without a login. It fills itself from your records, so when you publish a sermon, a belief, a missionary or an event, it shows on the website at once. The **member portal** is a private app for your members, where each person sees their own household, sign-ups, giving and groups.

Users with the Church Manager role profile can change the website. They have the Website Manager role, which a Church Branch Manager does not have. Members and visitors need no training: the website and the member portal work on any phone or computer.

The Web Site workspace shows the number of web pages, a chart of web pages by type and a preview of your home page. Click the preview to open the website in a new tab. The sidebar lists **Web Pages**, **Web Forms**, **Website Settings**, **Website Themes**, **About Us Settings** and **Contact Us Settings**. **Portal Settings**, **Website Script**, **Website Sidebars** and **Website Route Meta** are in the **Setup** folder.
